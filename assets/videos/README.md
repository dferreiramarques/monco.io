# Hero Video

Place your hero video here as `hero.mp4`.

Specs recomendados:
- Duração: 10–20 segundos em loop
- Resolução: 1920×1080 mínimo, 4K ideal
- Codec: H.264 para compatibilidade máxima
- Tamanho: idealmente < 8MB (usar HandBrake para comprimir)
- Conteúdo sugerido: espaço de trabalho/studio, ambiente noturno urbano, abstract motion

Para ativar o vídeo, remove o comentário no bloco <video> em index.html:
<!--
<video class="cinema-video" autoplay muted loop playsinline ...>
-->
